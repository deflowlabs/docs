DeFlow account access is currently invitation-only. You need a modern browser, an approved invitation, and a compatible wallet. The current release uses Ethereum Sepolia.

## Before you start

- Use a wallet intended for testing. Do not reuse a wallet that holds valuable mainnet assets.
- Confirm the network is **Ethereum Sepolia (11155111)**.
- Obtain a small amount of faucet-issued Sepolia ETH for gas.
- Never share a seed phrase, private key, or one-time authentication code with DeFlow support.

## Create the account

::step-guide
:::step{title="Open the official application" n="1"}
Follow the invitation supplied by DeFlow or an authorised participant. Verify the domain before connecting a wallet.
:::
:::step{title="Authenticate and connect your wallet" n="2"}
Complete the supported sign-in flow, then approve only the requested Sepolia connection.
:::
:::step{title="Enter the invitation" n="3"}
Submit the invite or referral code. A code associates your account with the invitation; it never requires a wallet signature by itself.
:::
:::step{title="Choose a public username" n="4"}
Use a name that does not reveal personal or confidential information. Your identity-verification data is handled separately.
:::
::

After account creation, complete [Identity verification](/getting-started/identity-verification). Verification and readiness checks may restrict deal actions even when sign-in succeeds.

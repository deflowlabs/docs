## Before starting a workflow

Check [Product availability](/getting-started/product-availability) before using a restricted capability. In the current private-beta environment, use only dedicated Sepolia wallets and verify every asset and address. If behaviour differs from a guide, stop and preserve the visible IDs and transaction evidence before contacting support.

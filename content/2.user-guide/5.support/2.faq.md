## Does the current release use assets with monetary value?

No. It uses real contracts on Ethereum Sepolia with Sepolia ETH and TestUSDC, both of which have no monetary value.

## Which settlement asset is supported?

The current allowlisted asset is TestUSDC at `0x0F5D9F6546aa791De4B9543d57f8C19b668Eb10E`. Sepolia ETH is used for gas.

## Is DeFlow externally audited?

No independent smart-contract audit has been engaged yet. An internal audit-preparation document defines the intended scope.

## Does DeFlow control escrowed assets?

Assets are held by per-deal contracts, but the current governance address has explicit dispute, refund, settlement, and emergency rerouting powers. See [Smart-contract security](/user-guide/security/smart-contract-security).

## What are the fees?

The configured commercial schedule ranges from 1.50% to 0.15% by notional tier, while the current Sepolia deployment manifest records a separate 1.00% global fee value. Review the quote shown for the specific transaction and [Fees and supported assets](/user-guide/trading/fees-and-supported-assets).

## Are Syndicates available?

Yes. Syndicates are available in private beta and use FIFO allocation with a separate Sepolia escrow for each approved investor. Complete environment validation is pending. Pro-rata allocation, pooled escrow, and an on-chain SyndicateController are planned.

## Are portfolio analytics available?

The dashboard provides limited deal, volume and activity summaries. Advanced portfolio, treasury and risk analytics are planned and must not be presented as available.

## Is identity verification legally certified?

The current release uses a third-party sandbox verification flow. DeFlow's legal, privacy, AML, custody, and compliance terminology is awaiting qualified counsel review.

## Where are the developer API documents?

DeFlow has no supported public API or SDK at this stage. A disabled “Developer Guide — Coming soon” label remains visible in the site navigation and will become a link only when external interfaces are stable enough to support.

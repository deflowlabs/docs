Use this procedure when your account has issuer access. Complete account and readiness setup first.

## Before you start

- Confirm the interface shows **Sepolia**.
- Keep Sepolia ETH available for transaction gas.
- Confirm the asset is approved for the current environment.
- Decide the soft cap, hard cap, minimum ticket and future funding deadline.
- Decide who should receive the shared link.

## Create the draft

1. Open **Deal Room** and select **New Deal**.
2. Select **Syndicate Raise**.
3. Under **Basics**, enter the asset symbol, display currency, soft cap, hard cap, minimum ticket and funding deadline.
4. Confirm that the soft cap does not exceed the hard cap and that the minimum ticket is greater than zero.
5. Continue to save the draft.

## Choose access and allocation rules

1. Select the access mode available to your issuer account.
2. Treat the shared URL as sensitive even when the screen says **Public**; the current release is invitation-only and is not a public marketplace.
3. Review the allocation policy. The current working policy is **FIFO**.
4. Do not promise pro-rata treatment—the visible pro-rata option is marked coming soon and is not operational.

## Review and publish

1. Check every term on the review screen, especially asset, caps, minimum ticket and deadline.
2. Select **Continue**, then **Publish Syndicate**.
3. Publishing locks normal draft editing and allows allocation requests.
4. Copy the generated Syndicate URL and share it only with intended investors.
5. Preserve the Syndicate ID and any visible error when reporting a defect.

::callout{type="note"}
The current flow is under integration validation. If a save, publish, approval, escrow, or funding action does not match this guide, stop and contact support rather than recreating the raise repeatedly.
::

## After publication

Monitor requested, approved, and funded allocations. In the current release, confirm state using the allocation list and on-chain evidence rather than treating the aggregate progress display as a financial record.
